# Foto Cavalcavia

App per il telefono: si scattano le foto dei difetti dei cavalcavia, già assegnate al difetto, e ogni foto va da sola nella cartella di Google Drive collegata.

- App: `index.html` (si apre dal browser e si installa con «Aggiungi a schermata Home»).
- `script/Codice.gs`: lo script Google (Apps Script) che riceve le foto nel Drive.

Nel codice non ci sono foto né password: il link dello script si dà solo ai colleghi.
